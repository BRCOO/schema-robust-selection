# Launch scripts

The exact shell scripts used to run the experiments of the paper, kept for reference. They were written for the authors'
workstation (Git Bash on Windows; interpreter `/d/BRCoo/miniconda/python`; repository at `/d/ALL PROJECT/...`), and some
call helper scripts that are not part of this release. Adjust the interpreter and paths before use; the commands in the
top-level README are the portable version.
